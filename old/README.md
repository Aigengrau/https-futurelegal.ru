# Архив оригинального сайта (Tilda)

Снимок `https://futurelegal.ru` со всеми 13 страницами, сделанный
**28 августа 2026 года**, — до переписывания на Astro. Служит эталоном:
копия сверялась именно с ним.

## Как открыть

Откройте `index.html` в браузере. Копия полностью автономна: 238 файлов
(изображения, CSS и JS Tilda) лежат в `assets/`, ссылки переписаны на
локальные пути, переходы между страницами работают офлайн.

```
old/
├── index.html, o-firme.html, services.html, … (13 страниц)
└── assets/
    ├── css/   # 21 файл: 13 постраничных бандлов + фреймворк Tilda
    ├── js/    # 35 файлов Tilda, включая jQuery 1.10.2
    └── img/   # изображения всех страниц
```

## Отличия от того, что было в сети

- **Аналитика удалена** — `tilda-stat` вырезан, `dns-prefetch` убраны.
- **Формы не работают** — они и в оригинале уходили на бэкенд Tilda.
- **Видео подгружается с RuTube** — внешний плеер, нужен интернет.

## Зачем это здесь

Чтобы заявление «копия 1:1» можно было проверить: откройте архив рядом
с новой версией и сравните. Методика сверки и полный список расхождений —
в [корневом README](../README.md).

Папка не участвует в сборке: она вне `src/` и исключена в `tsconfig.json`.
