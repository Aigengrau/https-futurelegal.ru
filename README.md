# futurelegal.ru

Сайт юридической компании Future Legal — **копия 1:1** оригинала, собранного
в Tilda, переписанная на Astro. Все 13 страниц.

Оригинал сохранён в [`old/`](./old) как автономная офлайн-копия и служит
эталоном, с которым сверялась вёрстка.

| | |
|---|---|
| **Стек** | [Astro 5](https://astro.build) · TypeScript |
| **Рендеринг** | статическая генерация, ноль фреймворков на клиенте |
| **Страниц** | 13 · 124 блока |
| **Своего JS** | ~5 КБ: анимации, счётчики, ленивые картинки и видео, формы |

---

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # сборка в dist/
npm run preview
npm run check    # проверка типов
```

## Как это устроено

```
src/
├── data/
│   ├── manifest.json     # список страниц
│   ├── pages/*.json      # разметка блоков, мета и список стилей на страницу
│   └── site.ts           # настройки форм и аналитики
├── layouts/Base.astro    # <head>, подключение стилей, весь рантайм
├── styles/base.css       # то, что Tilda досчитывала в JS
└── pages/[...slug].astro # один маршрут на все 13 страниц
public/
├── styles/*.css          # 21 таблица стилей — дизайн-спецификация
└── assets/img/*          # 96 изображений
```

**Стили каждой страницы подключаются отдельно, как в оригинале.** Tilda
компилирует под каждую страницу свой бандл, и в них 676 конфликтующих
определений одних и тех же селекторов: `.t-title` на одной странице и на
другой — это разные правила. Склеить их в один файл нельзя, иначе часть
страниц сломается. Поэтому `<link>` на каждую страницу свой.

От Tilda не осталось ни строчки JavaScript — ни jQuery, ни её 35 скриптов.

### Что переписано вручную

| Поведение | Было | Стало |
|---|---|---|
| Появление при прокрутке | `tilda-animation` | `IntersectionObserver`, класс `t-animate_started` |
| Счётчики (`animatednumber`) | `tilda-animation` | отсчёт по `requestAnimationFrame` |
| Бегущие строки (`sbs`) | `tilda-animation-sbs` | Web Animations API |
| Ленивые картинки | `tilda-lazyload` | `data-original` → `src` + нативный `loading="lazy"` |
| Видео | `tilda-video` | iframe RuTube по `IntersectionObserver` |
| Формы | `tilda-forms` | перехват отправки (см. ниже) |

Анимации используют **собственные стили Tilda** — они уже в бандле и задают
и начальное, и конечное состояние. Свой код только ставит стартовый transform
и добавляет класс в нужный момент, то есть повторяет ровно то, что делал
оригинальный скрипт.

Элементы, уже находящиеся в зоне видимости, раскрываются синхронно — без
ожидания первого асинхронного колбэка. Без JS ничего не скрывается вовсе,
при `prefers-reduced-motion` анимации выключаются.

## Формы не отправляются

Формы принимали заявки через бэкенд Tilda. Без подписки отправлять их некуда,
поэтому они оставлены **визуально идентичными, но неактивными**: при отправке
показывается сообщение, что приём заявок не подключён. Молча терять введённое
пользователем — хуже, чем честно сказать.

Чтобы включить приём, поставьте в `src/data/site.ts` `forms.inert = false`
и добавьте `action` на любой обработчик (Formspree, собственный эндпоинт).

## Точность копии

Каждая страница рендерилась в одном браузере из архива и из копии, после чего
сравнивалась попиксельно. Расхождение считается после компенсации сдвига всей
страницы: headless-браузер даёт одному из документов полосу прокрутки, а
другому нет, и центрированный макет уезжает на половину её ширины — это
артефакт съёмки, а не разница между страницами.

**Среднее расхождение — 0.58 %.**

| Страница | Расхождение | | Страница | Расхождение |
|---|---|---|---|---|
| brendnow | 0.24 % | | experience | 0.81 % |
| monitor | 0.24 % | | services | 0.79 % |
| world | 0.24 % | | awards | 0.97 % |
| proekt | 0.24 % | | index | 1.00 % |
| geo | 0.25 % | | o-firme | 1.85 % |
| reviews | 0.25 % | | | |
| career | 0.26 % | | | |
| contacts | 0.47 % | | | |

Остаток — сглаживание шрифтов: контейнер Tilda остаётся на собственном слое
композитинга, из-за чего Chrome рисует текст полутоновым сглаживанием вместо
субпиксельного. Глифы те же, отличается только цветная кайма.

Единственное содержательное расхождение — фотография на `/o-firme`. Там два
наложенных варианта кадра; в архиве верхний не успевал подгрузиться к моменту
съёмки, и виден был нижний. Копия грузит оба, поэтому показывает верхний —
то же, что увидит живой посетитель оригинала, долистав до этого места.

### Что чинилось по дороге

1. **Видео не было видно.** Высоту контейнера задавал скрипт Tilda, в CSS
   её нет. По оригиналу измерено ровно 16:9 — теперь задано в стилях.
2. **Пропадали блоки с анимацией.** Стили Tilda ставят `opacity: 0` и ждут
   класс `t-animate_started` от скрипта, которого больше нет.

## Деплой

GitHub Pages через Actions ([`deploy.yml`](./.github/workflows/deploy.yml)):

1. Запушить `main`.
2. **Settings → Pages → Source: GitHub Actions.**

Если раздел Pages в репозитории ещё ни разу не включали, первый запуск упадёт
на шаге `Configure Pages`: токен воркфлоу умеет переключать источник, но не
создавать сайт с нуля. Включите Pages один раз руками — дальше всё само.
